# mewmori-site

Сайт https://mewmori.com — статика, GitHub Pages. Он же витрина, он же комплект
документов, который Robokassa требует при регистрации магазина.

```
index.html      лендинг
prices.html     прайс-лист и как купить
payment.html    оплата, безопасность платежей, порядок получения ключа
refund.html     возврат
offer.html      публичная оферта (договор)
privacy.html    политика конфиденциальности
contacts.html   контакты и реквизиты продавца
404.html        страница ошибки
en/             то же самое по-английски
assets/         стили, шрифт, иконка, спрайты котов
fill.sh         подстановка реквизитов из requisites.env
```

Дизайн повторяет приложение: цвета и форма панелей взяты из
`PersonaNoirDesign.swift` (`PersonaControlShape` — прямоугольник со ступенчатыми
углами, в CSS собран из двух слоёв с общим `clip-path`), шрифт — тот же Handjet
из `Mewmori/Resources/Fonts`, лицензия OFL лежит рядом в `assets/fonts/OFL.txt`.

## Языки

Русский лежит в корне, английский — в `en/` с теми же именами файлов.
Версии всегда доступны по своим адресам; язык меняется ссылками RU/EN в шапке.
Автоматического перенаправления по языку браузера нет: оно мешает поисковым
роботам и может отправить пользователя по ссылке не на ту языковую версию.

Английские версии оферты, возврата и политики — перевод для удобства; в каждой
стоит оговорка, что юридическую силу имеет русский текст. Меняешь русский —
меняй и английский, иначе оговорка перестанет быть правдой.

Никакой сборки: файлы отдаются как есть. Локально —
`python3 -m http.server 8000` и открыть http://localhost:8000.

## 1. Реквизиты

```bash
cp requisites.env.example requisites.env
$EDITOR requisites.env
./fill.sh
```

`requisites.env` в `.gitignore`. Скрипт правит HTML на месте, поэтому для смены
значений сначала верни плейсхолдеры: `git checkout -- '*.html'`.

Robokassa не пропускает магазин без ФИО, ИНН, работающей почты и телефона —
плейсхолдеры на живом сайте гарантированно вернут заявку на доработку.

## 2. Публикация

```bash
git init && git add -A && git commit -m "Mewmori site"
gh repo create BarredEwe/mewmori-site --public --source=. --push
```

Репозиторий должен быть публичным: кастомный домен на Pages в приватном репо
требует платного плана.

Settings → Pages → Source: **Deploy from a branch**, ветка `master`, папка `/ (root)`.
Через минуту сайт живёт на `https://barredewe.github.io/mewmori-site/`.

## 3. Домен и HTTPS

`mewmori.com` обслуживается GitHub Pages. В DNS должны быть только следующие
записи для сайта:

```
A     @   185.199.108.153
A     @   185.199.109.153
A     @   185.199.110.153
A     @   185.199.111.153
AAAA  @   2606:50c0:8000::153
AAAA  @   2606:50c0:8001::153
AAAA  @   2606:50c0:8002::153
AAAA  @   2606:50c0:8003::153
CNAME www barredewe.github.io.
```

`CNAME` в корне репозитория должен содержать `mewmori.com`. В Settings → Pages
задаётся тот же **Custom domain**. После проверки DNS GitHub выпускает сертификат
для apex и `www`; затем включи **Enforce HTTPS**. При корректных DNS-записях
GitHub Pages сам перенаправляет `www.mewmori.com` на `mewmori.com`.

Если домен на Cloudflare: записи должны быть **DNS only** (серое облако), иначе
Pages не сможет выпустить сертификат. После выпуска проксирование можно включить.

## 4. Почта на домене

Robokassa пишет на адрес из заявки, и он же указан в оферте. Бесплатный вариант —
Cloudflare Email Routing (`support@mewmori.com` → личный ящик) или Яндекс 360
для бизнеса.

## 5. Индексация

`robots.txt` разрешает обход и указывает на `sitemap.xml`. После каждого первого
публичного развёртывания добавь домен в Google Search Console, отправь
`https://mewmori.com/sitemap.xml` и запроси индексирование главной страницы
через URL Inspection.
